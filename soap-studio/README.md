# Soap Studio

Public support site. `public/` contains the static site and its licensed assets; `content.json` keeps the document copy. Firebase Hosting serves `public/` as its site root for project `soap-studio-apptunes`.

Support: https://soap-studio-apptunes.web.app/soap-studio/support  
Privacy: https://soap-studio-apptunes.web.app/soap-studio/privacy  
Terms: https://soap-studio-apptunes.web.app/soap-studio/terms

The app's custom-domain URLs require the separate apptuneslabs.com domain connection before they will work.
